# Solidity Learning Projects

Learning Solidity, smart contracts, Ethereum, and blockchain protocol engineering through hands-on projects.

## Project 1: SimpleStorage

### Overview

A beginner Solidity smart contract that stores and updates an unsigned integer.

### Features

- Store a number using `setNumber()`.
- Read the stored number using the automatically generated `number()` getter.
- Increase the stored number by one using `increment()`.

### Concepts Learned

- Solidity contract declarations
- State variables and persistent storage
- Functions and parameters
- Public visibility
- Basic state changes

### Technology

- Solidity
- Ethereum Virtual Machine (EVM)

### Learning Goals

- Learn automated smart contract testing
- Understand gas costs and transaction execution
- Study common vulnerabilities and secure contract design

This repository is a work in progress as I build practical blockchain development skills.
